它是为这几种人做的

  
共同点只有一个：没有人替你安排时间，所以你得自己看见它。

  

  
每天花的功夫是 拖几下。一周之后，你的时间长什么样就摆在那了，然后才谈得上改。






  
只做三件事

  
不做日历、不做番茄钟，只把「纸上那根时间轴」做顺手。

  

    
手画，即记录
顶部是荧光笔色板，一种颜色一类事。在轴上拖一下就是一段，时长自动写在中间。前一晚用「计划」画的斜线块，第二天被真实色块盖过去，像纸上的铅笔和荧光笔。

    
一句话，让 AI 画
块底下有个输入框。写「刚跑步半小时」「12 点半到 1 点吃饭」，它算好起止、挑好颜色、写回笔记；说不清时长它会追问一句。也可以把随附的 skill 交给你自己的 Agent，让它替你记。

    
Markdown 是本体
时间轴是笔记里一个 timeline 代码块，一行一段时间。画的每一笔都写回源码，改源码时间轴也跟着变。Git 能 diff，同步不会丢，卸载插件也还能读。

  

  

    
```timeline
date: 2026-09-05
plan 09:00-12:00 写作
07:00-08:30 睡觉 赖床
09:15-11:45 写作 第三章初稿
11:45-12:30 吃饭
@13:10 有点困，散步十分钟
```

    
演示块的源码就是这样几行。plan 是计划层，@ 是一个时间点的批注，时长不用写，渲染时算。

  

  
同一个块里还能放 打卡、待办 和 每日一句，把待办拖到时间轴上就成了计划。要不要用，随你。






  
两分钟装好

  
还没上社区目录，先用 BRAT 装。三步，不用手动复制文件。

  

    
1 · 装 BRATObsidian 设置 → 第三方插件 → 浏览，搜 BRAT，安装并启用。

    
2 · 加仓库BRAT 设置里点「Add Beta plugin」，填 IvyYang1999/modular-diary。

    
3 · 启用回到第三方插件列表启用 Modular Diary。在任何笔记里输入 ```timeline，或用命令面板「插入 Modular Diary 时间轴」。

  

  
v0.2.0 · 免费 · 开源 · 桌面与手机 · Obsidian 1.8.7 以上 · 编辑与阅读视图都能画 · 快速记录需要你自己的模型 API Key（GLM / DeepSeek / OpenAI / Claude 都行）

  

    
数据存在哪里？
就在那篇笔记里，一个 timeline 代码块。没有数据库、没有附属文件。随 iCloud / Git / Obsidian Sync 一起走，没装插件的地方打开也能读。

    
不配 AI 能用吗？
完全可以。画色块、备注、计划层、统计都不联网。快速记录是可选项：没填 API Key 时那一行只是一句「去设置填 Key」的提示，不想看见可以在块菜单里把这个组件隐藏。

    
手机上能用吗？
能看也能画，Obsidian 移动端一样渲染。快速记录在手机上走模型 API；本机 Claude CLI 这个后端只有桌面端有。

    
颜色和分类怎么定？
设置里维护一张「分类 → 颜色」表，这就是你的荧光笔色号。笔记里只写分类名，改颜色不会动历史记录。

    
已经装过旧版 Oneday，怎么迁移？
新版的插件 ID 是 modular-diary，不是旧版的原位更新。先在本机备份旧插件目录和设置；关闭旧插件，安装新版后把旧目录的 data.json 私下复制到新目录，再启用新版。不要同时启用两份：它们都会接管 timeline 代码块。旧的快捷键和自定义 CSS 也需要重新对应。完整迁移步骤
