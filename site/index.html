六个模块，用哪个摆哪个

  
它们读写同一段 Markdown，所以一处记录，处处更新。每个模块都能拖动、缩放、隐藏，摆好的布局可以设成新笔记的默认。

  

    
时间轴
选一支荧光笔，在轴上拖一下就是一段时间，时长自动写在中间。计划是斜线，记录是实色，实际发生的盖住计划。

    
第三章初稿实际 2.5h / 预计 4h
背 list 5预计 45m
待办
给待办估个时长，拖到时间轴上就成了计划。做完回头看，实际花了多久是算出来的，不是猜的。

    
运动半小时✓ 已打卡
每周阅读 5 小时本周 3.5h / 5h
打卡
「每天运动半小时」「每周阅读五小时」这样的规则，时间轴上画够了自动打卡，不用手点。

    
成效的关键时刻：13 天，坚持下去。
每日一句
句库里的话按日期轮到哪句显示哪句，底色是你挑的那支荧光笔。句库就是一个文本框，一行一句。

用时统计
今天每类事花了多久，一排横条。不用导出，不用报表，抬眼就看见。

    
刚跑步半小时记录
16:00–16:30 运动已写回笔记
快速记录
写一句「刚跑步半小时」，它算好起止、挑好颜色、写回笔记。需要你自己的模型 API Key，不填就不出现。

共同点只有一个：没有人替你安排时间，所以你得自己看见它。同一个插件，三个人会拼出三张不一样的页面。

  

  
每天花的功夫是 拖几下。一周之后，你的时间长什么样就摆在那了，然后才谈得上改。






  
Markdown 是本体

  
整块面板是笔记里一个 timeline 代码块。你在界面上做的每一件事都写回这几行，改这几行界面也跟着变。

  

    
```timeline
date: 2026-09-05
layout: text@0,0,6,4 todos@0,4,6,5 timeline@6,0,6,45
todo: id="t1" done=false estimate=240 title="第三章初稿"
---
plan 09:00-12:00 写作
09:15-11:45 写作 第三章初稿 [todo:t1]
11:45-12:30 吃饭
@13:10 有点困，散步十分钟
===
上午别开消息，写完再看。
```

    

      
MD 是 Modular Diary，
也是 .md。

      
没有数据库，没有附属文件。Git 能 diff，同步不会丢，卸载插件之后它仍然是一段读得懂的文字。把随附的 skill 交给你的 Agent，它也能直接替你记。

    

  






  
常见问题

  

    
数据存在哪里？
就在那篇笔记里，一个 timeline 代码块。没有数据库、没有附属文件。随 iCloud / Git / Obsidian Sync 一起走，没装插件的地方打开也能读。打卡规则、句库和荧光笔色表是全局设置，存在插件自己的配置里。

    
模块能自己摆吗？
能。块里每个模块都可以拖动换位、拖边缘改大小、右键隐藏，从「更多」菜单里加回来。布局写在块头的 layout 一行里；摆顺手了可以「设为新块默认」，之后每篇新日记都是这个样子。

    
不配 AI 能用吗？
完全可以。时间轴、待办、打卡、每日一句、统计都不联网。快速记录是可选模块：没填 API Key 时它只是一句「去设置填 Key」的提示，不想看见就把这个模块隐藏掉。

    
手机上能用吗？
能看也能画，Obsidian 移动端一样渲染。快速记录在手机上走模型 API；本机 Claude CLI 这个后端只有桌面端有。

    
颜色和分类怎么定？
设置里维护一张「分类 → 颜色」表，这就是你的荧光笔色号。笔记里只写分类名，改颜色不会动历史记录。

    
已经装过旧版 Oneday，怎么迁移？
新版的插件 ID 是 modular-diary，不是旧版的原位更新。先在本机备份旧插件目录和设置；关闭旧插件，安装新版后把旧目录的 data.json 私下复制到新目录，再启用新版。不要同时启用两份：它们都会接管 timeline 代码块。旧的快捷键和自定义 CSS 也需要重新对应。完整迁移步骤
